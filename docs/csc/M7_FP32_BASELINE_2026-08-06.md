# M7 FP32 Baseline (2026-08-06)

This document freezes the validated FP32 M7 state used as the starting point
for the FP16 M7 branch.

## Precision and scope

- Matrix values, vector operands, products, BGA values, partial results, and
  host reduction values use the existing FP32 M7 implementation.
- The production BGA defaults are 64 accumulator entries, compare width 64,
  and output queue depth 64.
- The BGA validation-only mode stops after compute and BGA drain.
- The transport-only mode stops after BGA, partial-result writeback, and host
  readback transport. It deliberately excludes host reduction.

## Transport-only baseline

Physical image: `/tmp/csc_cant_m7_sparsepim_cluster`

Command:

```bash
CSC_EXTERNAL_IMAGE=/tmp/csc_cant_m7_sparsepim_cluster \
CSC_BGA_WRITEBACK_ACCEPTS_PER_CYCLE=8 \
./sim \
  --gtest_filter=CSCM7BFullRunTest.ExternalMatrixWritebackReadbackOnly
```

The reported `T_writeback` overlaps compute and BGA execution. The comparable
end-of-scope timing is therefore `transport_result_delivered_cycle`, not the
sum of the individually reported phase durations.

## Required regression properties

- A wide validation consumer accepts at most one output from each BG per
  cycle.
- Validation and partial-writeback consumer widths must be in `[1, 64]`.
- Completion is determined by contribution conservation and BGA drain;
  floating-point semantic comparison is reported separately and does not
  prevent termination.
- Transport-only execution must preserve contribution count, physical record
  count, and useful/transferred/padding byte counts.

Regression command executed on 2026-08-06:

```bash
./sim --gtest_filter=CSCM7A2CompletionDrainTest.*:CSCM7BPartialWritebackTest.*:CSCM7BHostReadbackTest.*:CSCM7BHostReductionTest.*
```

Result: 72 tests executed, 71 passed, and the one external-image test was
skipped because `CSC_EXTERNAL_IMAGE` was not set. There were no failures.
