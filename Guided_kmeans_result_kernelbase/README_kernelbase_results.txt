This directory archives analytical model results generated with the previous
GPU baseline interpretation.

The target latencies used for these model versions were derived from locally
measured GPU baseline values: GPU kernel execution time plus per-iteration
overhead. These values are not the original-author GPU baseline latencies used
by the SparsePIM paper's reported speedups.

These results should be treated as kernel-base historical results. They are
useful for tracing the earlier analytical-model development process, but they
should not be used as the current target for BV-series models or for
paper-baseline SparsePIM latency evaluation.
